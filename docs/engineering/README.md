# Kỹ thuật và phát triển

- [ARCHITECTURE.md](ARCHITECTURE.md): ranh giới module, state/session,
  content/text, world và authoring.
- [DEVELOPMENT.md](DEVELOPMENT.md): quy tắc sửa code, thêm nội dung và kiểm chứng.
- [REPOSITORY.md](REPOSITORY.md): chính sách Git/local asset và khôi phục khi chuyển máy.

`repository-local-files.json` là inventory lịch sử của lần dọn Git trước đây.
Các đường dẫn bên trong là đường dẫn **tại thời điểm ghi nhận**, được giữ nguyên
để phục hồi revision cũ; không dùng nó làm danh sách file hiện đang tồn tại.
Các lần chuyển/xóa tài liệu mới được ghi ở [maintenance](../maintenance/README.md).

[Mục lục tài liệu](../README.md).
