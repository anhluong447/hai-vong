- [01-hom-nay.png](01-hom-nay.png): default overview, with links to Khuê's dossier, teammate feedback, publishing and appointments.

These are raster layout prototypes, not runtime assets or gameplay specifications. Gameplay costs, deadlines, money, receipt contents and other example data are illustrative. Generated lettering and incidental background text are not canonical content.

Review: all three images were inspected in the generation output. The intended ownership distinction and personal-dossier action costs are visible. Sidebar widths, icons, highlight treatment and status-strip placement vary across images and need a shared component specification before implementation. No teammate-assignment detail or publishing screen is included in this first set.

The existing coastal replica references are preserved. This exploration does not modify the fixed replica scope or runtime UI. Original generated files remain in the generator directory; workspace copies were verified with SHA-256.
