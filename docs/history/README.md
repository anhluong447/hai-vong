# Tài liệu nguồn còn giá trị lịch sử

Các file ở đây được giữ vì còn nội dung nguồn cần đối chiếu, không dùng làm
hướng dẫn triển khai hiện tại.

- [Bible v1](narrative/game_story_bible.md) và
  [proposal](narrative/BIBLE-CLB-BAO-CHI-PROPOSAL.md): nguồn lore và các giả định
  trước [bible v2](../design/narrative/game_story_bible_v2.md).
- [Draft công thức](formula/Draft.md) và [mô phỏng Python](formula/sym.py):
  nguồn đối chiếu bộ công thức sandbox. Không thay thế code runtime hiện tại.
- [Kế hoạch component UI v1](ui/UI-COMPONENTS-PLAN.md): được bộ concept ban đầu
  tham chiếu, giữ để bảo toàn bối cảnh tạo art; phạm vi đã được roadmap replica
  và menu sáu tab cập nhật.
- [Layout menu Stage 5 viết tay](ui/MENU-STAGE5-LAYOUT.md): bản phân tích concept
  cũ, được tách khỏi output generator Stage 0 để bảo toàn nội dung thiết kế.

Checklist triển khai đã hoàn tất, đặc tả một layer đã được thay thế, prompt
refactor engine chung và screenshot preview không còn dùng đã được xóa.

thư mục lịch sử này.
