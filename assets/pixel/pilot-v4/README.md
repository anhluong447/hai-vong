# Khuê: four-direction walk trial

**Rejected after visual review.** Removed from the active atlas; Khuê uses pilot-v3 again. Keep this sheet and its sources for diagnosis only. Technical tests passed, but that did not establish acceptable anatomy or motion.

Visible problems: lower-body proportions and arm shapes change between generated poses; limbs and satchel merge into unclear clusters; shading changes do not consistently describe the same volumes. Freezing the upper 24px cannot fix the remaining body's structure and may introduce a mismatch at the join. This pipeline should not be expanded into another full sheet until a small, coherent pose sequence passes visual review.

2026-10-06. Sheet: 256×384, 8 columns × 8 rows, native frames 32×48, pivot (16,46).

Rows 0–3: down, left, right, up walks, eight frames per direction. The approved left cycle is copied exactly from pilot-v3. The other directions use individually generated poses guided by contact → closing → passing → opening, followed by the opposite step. Right-facing art is generated separately to preserve the satchel side.

Rows 4–7: existing down/left/right/up idle (columns 0–3) and talk (columns 4–7), unchanged. This is 32 completed walk frames plus 32 existing idle/talk frames, not 64 newly generated poses.

Limb targets in the prompts: roughly 4px thighs, 3px calves/forearms, 3×3px hands and 4px-wide shoes. Foreshortening changes projected length, not the intended limb mass. Generated raster art remains a prototype: clothing/shading and arm arcs can still vary between poses.

`tools/import_khue_full_walk.ps1` samples each entire source canvas on a fixed 32×48 grid, thresholds transparency, and maps colors to the existing Khuê palette. The upper 24px are copied from the approved idle master for each direction; the lower 24px retain the generated pose. There is no individual frame recentering or rescaling. Left walk and idle/talk are copied unchanged. Old sheets remain in pilot-v2/pilot-v3.

Sources, guides, prompts and selected generation records: `../khue-full-walk/`. Guides are technical diagrams generated by `tools/prepare_khue_full_walk.ps1`; character artwork uses the built-in imagegen tool. Original imagegen files are preserved outside the repository as well as copied here.

Preview all directions together at `/tools/khue-animation-lab.html`: slow playback, pause, frame stepping, onion skin, idle/talk and complete sheet download. Normal walk cadence matches the game: 48px per eight-frame cycle, nominal movement 16px per 180ms.

Validation after atlas integration: browser suite **56/56 passed**; gallery DOM confirms pilot-v4 loaded and all eight walk phases played in all four directions. Pixel comparison against pilot-v3 reports zero changes to the approved left cycle and idle/talk rows. All new frames have binary alpha, clear cell margins and the existing limited palette.
